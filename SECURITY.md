# Security policy

BastionGlass is an early prototype, not certified security infrastructure. No version is represented as vulnerability-free. Until independent review and broader validation, use it only as an additional source of bounded observations.

Report a suspected defect privately to the repository maintainer through an available private security-reporting channel. Do not place credentials, private source, captured traffic or exploit details in a public issue. If no private channel is enabled, request one without including sensitive details. Do not assume this repository has a funded bounty or incident-response SLA.

Use benign reproduction material. No unauthorized testing, exploitation, scanning of other users' data or host/container escape attempts are requested. The maintainers should acknowledge, triage, minimize, fix, test and document confirmed defects; no response-time guarantee is currently offered.

For an issue affecting OpenAI infrastructure, use the verified official disclosure route documented in `docs/NETWORK_AND_REPORTING.md`, subject to authorization and data minimization. A vulnerability in BastionGlass is not automatically an OpenAI vulnerability.
